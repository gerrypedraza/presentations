The Dial Depends on the Goal

Planned visual (V5)

  • Being agentic is a setting you choose, not a quality score.

Glossary

The basics

Artificial intelligence (AI)
The umbrella term for systems that do tasks that normally need human judgment, such as recognizing speech, predicting outcomes, or writing text.
Machine learning
How most modern AI is made: the system learns patterns from examples instead of following rules someone wrote. A rules-based accessibility checker is not machine learning; nobody trained it.
Model
What training produces: learned patterns that turn an input into an output. When people say “the AI,” they usually mean the model.
Specialized model
A model trained for one function, such as captions, text-to-speech, OCR, or a risk score. It cannot do anything else.
General model (LLM, foundation model)
A model that learned language broadly, such as Opus, GPT, or Gemini. It can do many tasks depending on the instructions it gets.

Doors and setups

Door (interface)
How you reach a model: a chat app, an assistant inside your tools, a command line, or your own script. The same model can sit behind each door; the door decides what it can reach.
API
The way a script talks to a model directly. A script can do exactly what it is coded to do and nothing more.
Connector
A link that lets an AI app reach another system, such as your email, files, or LMS.
Workspace (sandbox)
A computer the AI can work in, separate from yours, where it can run code and create files.
Saved setup
Instructions plus files (plus skills) saved for reuse. Custom GPTs and Gems were saved setups; vendors are moving them into skills.
Skill
Written guidance, sometimes with scripts or files attached, that the model reads and follows. The model still conducts and can adapt. A skill guides the agent; a workflow replaces it.

Who decides the next step

Narrow AI
In this talk, reserved for specialized models: one model, one function. “Narrow” describes scope, not quality.
One-job tool
Anything that does one fixed step: a specialized model, a general model locked to one instruction (such as an alt-text script), or a plain tool.
Workflow
Several steps run in an order fixed in advance by a script, a no-code flow, or a person with a checklist. The model may do steps, but it never chooses the path.
Agent
A system where the model decides its own next step toward a goal, acts on things outside the conversation, checks the results, and adjusts.
Agentic system
Anthropic’s umbrella term covering both workflows and agents.
Agency
Discretion over how to act. The human sets the what; the agent gets discretion over the how.
Conductor (orchestrator)
Whoever decides the next step: you in chat, a script in a workflow, or the model in an agent. “Orchestrator” is the industry term.
Guided agent
A model that conducts while following a skill: it uses your preferred way of working but can loop back or adjust.
Open agent
A model that conducts with no skill or set process, improvising its steps.

Working safely

Delegation brief
A request written like a hand-off to a colleague: outcome, materials, what done looks like, boundaries, and checkpoints.
Plan mode
A permission checkpoint: the agent may read and research but takes no action until you approve its plan. You can always ask for it in your brief.
Checkpoint
A planned point where the agent stops and waits for a person to review before continuing.
Least access
Giving an agent only the files, apps, and permissions the task needs.
Rubber-stamping
Approving an agent’s work by reflex after it has been right several times. A human is in the loop on paper but not in practice.
Prompt injection
Hidden instructions inside a web page, email, or file that try to steer an agent that reads them.
